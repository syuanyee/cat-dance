# 漲停小貓產生器

純靜態、繁體中文、RWD 影片合成網站。使用者的圖片不會上傳。無套件、無 API Key、無後端。

## GitHub Pages 部署

1. 建立 GitHub repository，把本資料夾內的 `index.html`、`style.css`、`app.js`、`assets/cats.mp4` 及 `.nojekyll` 上傳到儲存庫根目錄。
2. 開啟 Settings → Pages，選擇 Deploy from a branch。
3. 選擇 main 分支與 / (root)，儲存。
4. 等待部署完成，開啟 Pages 顯示的 HTTPS 網址。

不需 npm install 或建置。檔案使用相對路徑，可放在 repository 子路徑。

## 本機預覽

在本資料夾開啟終端機，執行 `python -m http.server 8080`，瀏覽 http://localhost:8080 。請勿直接以 file:// 開啟，避免影片畫布安全限制。

## 操作

- 上傳 JPG、PNG、WebP 背景，畫布自動依原圖比例完整顯示，不裁切。
- 三隻小貓為一整組，可拖曳位置、拉動選取框右下角縮放，也可使用滑桿。
- 輸出比例依上傳圖片，支援鏡像與綠幕微調。為配合影片編碼，尺寸補齊偶數像素；圖片以 1:1 像素置入，不縮放；奇數尺寸僅在右側或底部補一個邊緣像素。
- 輸出完整約 11.7 秒素材，可保留原音；預覽預設靜音。
- 完成後點擊下載，支援系統檔案分享的裝置亦可分享／儲存。

## 技術與限制

Canvas 2D 每格色鍵去背、Web Audio 音軌合成、MediaRecorder 錄製 Canvas captureStream。執行時自動偵測 MP4 支援，無支援則輸出 WebM，不會把 WebM 假改成 .mp4。MediaRecorder 的格式偵測不保證裝置有足夠編碼資源，若原始圖片超過裝置編碼能力，輸出可能失敗，請換用可支援此尺寸的裝置。參考：https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static

輸出為即時錄製，耗時約等於素材長度。大尺寸圖片在低階裝置上可能掉幀或無法編碼。保持分頁可見；切到背景會取消輸出，避免產生不完整影片。不支援錄製的瀏覽器會停用輸出；iOS/Android 實機仍需自行驗證瀏覽器的編碼及儲存功能。

素材原為 H.265 綠幕影片，已預先裁去上下多餘綠幕並轉為 H.264/AAC，以提高網頁相容性。三隻小貓原片彼此遮擋，因此以整組調整。去背與最終合成均在使用者瀏覽器執行。圖片以原始像素尺寸保留，不縮圖；重新整理後不保留作品。

小貓影片與音樂來自使用者提供素材，公開部署前請確認有相應使用權。

背景保留原始解析度，小貓獨立以 648 × 600 處理後疊加。影片仍經有損壓縮；保留解析度不代表無損輸出。
